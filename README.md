# Лабораторная работа №5. Работа с реляционными БД через JdbcTemplate
**Вариант 7: Предметная область «Военнослужащий»**

## Описание проекта
В данной лабораторной работе произведена миграция приложения с использования ORM (Spring Data JPA / Hibernate) на чистый SQL с использованием `JdbcTemplate`. Приложение представляет собой REST API для управления данными военнослужащих, их званий и адресов проживания.

## Что было сделано:
1. **Удаление ORM:** Из файла `pom.xml` удалена зависимость `spring-boot-starter-data-jpa`. Классы предметной области (`Serviceman`, `Rank`, `Address`) очищены от JPA-аннотаций (`@Entity`, `@Table`, `@Id`, `@ManyToOne` и др.) и преобразованы в чистые POJO.
2. **Инициализация БД:** Созданы SQL-скрипты для автоматического развертывания структуры базы данных при запуске приложения:
    - `schema.sql` — содержит DDL-команды (`CREATE TABLE`) со строгим указанием внешних ключей.
    - `data.sql` — содержит DML-команды (`INSERT`) для заполнения таблиц начальными данными.
3. **Реализация Data Access Layer (DAL):** Написаны классы-репозитории на базе `JdbcTemplate`:
    - `ServicemanJdbcRepository` — реализует CRUD-операции с использованием параметризованных SQL-запросов и обработкой `GeneratedKeyHolder` для получения ID при вставке.
    - Реализован комплексный `LEFT JOIN` запрос для извлечения агрегированных данных из 3-х таблиц.
4. **Маппинг (RowMapper):** Разработан класс `ServicemanMapper`, реализующий интерфейс `RowMapper`. Он отвечает за ручное создание объектов `Serviceman`, `Rank` и `Address` из строк `ResultSet`, исключая проблему N+1 запросов.
5. **Адаптация REST-контроллера:** Бизнес-логика в `ServicemanRestController` (включая работу с DTO) адаптирована под новые возвращаемые типы `JdbcTemplate`.

## Стек технологий
* Java 21 / Spring Boot 4.1.1
* Spring JDBC (`JdbcTemplate`)
* База данных: H2 (In-Memory)
* Инструменты тестирования: Postman

## Запуск проекта
Запуск осуществляется через класс `Springlab5Application`.
База данных автоматически поднимается в памяти (H2) и накатывает скрипты `schema.sql` и `data.sql`.
REST API доступно по адресу: `http://localhost:8080/api/servicemen`
